# Differentiable-oracle training from a predicted 15-minute path

Date: 2026-08-06

## Question

Can a two-layer normalized GLU be trained end to end through the exact
differentiable exposure-value oracle, so that its predicted future path is
judged by the resulting oracle distribution rather than candle or cumulative
return error?

## Experiment

The model receives 120 consecutive completed one-minute BTCUSDT log returns
and emits the next 15 consecutive one-minute log returns. There is no direct
policy head. Both the predicted and realized paths pass through the same exact
hard-Bellman PyTorch oracle:

```text
past 120x1m returns -> two-layer GLU -> predicted 15x1m returns -> Oracle -> Q
realized 15x1m returns ------------------------------------------> Oracle -> P
loss = KL(P || Q)
```

Only the `Q` branch retains gradients. The realized `P` branch is detached.
The hard maximum, buy/sell boundary, and liquidation boundary are preserved,
so gradients follow the selected Bellman branches almost everywhere.

The oracle configuration is:

- one-minute forced hold and one-minute decision cadence;
- 15-minute value horizon;
- 101 actions over `[-100, 100]`, including exact zero;
- maximum effective exposure 250;
- friction 0.175%;
- temperature 0.01; and
- 10 bps/hour quote and asset borrowing, compounded to each minute.

Hard liquidation can make the predicted and actual distributions have
different exact-zero supports. The predicted probabilities therefore receive
a `1e-8` floor before forward KL is evaluated. Without it, valid examples can
produce infinite loss and unusable gradients.

The input is the raw one-minute return sequence; no moving-average components
are used. The corpus retains the common 3M warm-up cutoff used by the earlier
one-minute MA-depth comparison:

- train: 536,895 examples;
- validation: 248,175 examples; and
- sealed chronological test: 16,666 examples from the final 1,000,000-second
  source tail.

The model has 2,756,115 parameters: two normalized-GLU layers of width 512 and
15 path outputs. Training used batch size 2,048, BF16 for the GLU, FP32 for the
oracle, maximum 32 epochs, and early-stopping patience 8. It ran 30 epochs and
selected epoch 22.

## Results

The baseline is the oracle distribution generated by a constant zero-return
15-minute path. It is not a learned direct-distribution model.

| Metric | Validation zero path | Validation GLU | Test zero path | Test GLU |
| --- | ---: | ---: | ---: | ---: |
| Forward KL | 5.70142 | **4.06536** | 4.78756 | **3.69281** |
| Probability MSE | 0.00079654 | **0.00051020** | 0.00065245 | **0.00045385** |
| Total variation | 0.53327 | **0.52770** | **0.49034** | 0.52226 |
| Modal-action agreement | 58.81% | **60.31%** | **64.86%** | 64.30% |
| Expected-exposure MAE | **36.73** | 42.31 | **31.77** | 37.88 |
| Predicted entropy | 2.70272 | 3.36858 | 2.70272 | 3.36050 |
| Target entropy | 3.13027 | 3.13027 | 3.19653 | 3.19653 |
| Return-path MSE skill vs zero | 0% | -24.67% | 0% | -41.64% |
| Cumulative-return MSE skill vs zero | 0% | -25.77% | 0% | -44.60% |

Relative to the zero-path oracle, KL fell by 28.70% on validation and 22.87%
on the sealed test. Probability MSE fell by 35.95% and 30.44% respectively.
This confirms that useful gradients propagate through the exact oracle and
that the GLU learns a path whose induced soft distribution is closer under the
training objective.

Exact per-example KL percentiles are:

| Split | Model | P50 | P90 | P95 |
| --- | --- | ---: | ---: | ---: |
| Validation | Zero path | 1.53927 | 15.63879 | 16.08983 |
| Validation | GLU | **1.13613** | **15.46745** | **16.08146** |
| Test | Zero path | **0.91404** | 15.12294 | **15.75790** |
| Test | GLU | 1.14641 | **14.63730** | 15.78197 |

The validation improvement appears throughout the measured distribution. The
sealed test is mixed: GLU is worse at the median, better at P90, and almost
tied but slightly worse at P95. Because mean test KL nevertheless improves by
22.87%, much of its mean advantage comes from reducing losses in examples
beyond these reported percentiles rather than uniformly improving typical
examples.

## Equal-weight mean plus P50 objective

A second run made median KL an explicit training and selection term:

`loss = mean(batch per-example KL) + P50(batch per-example KL)`

The exact batch median is piecewise differentiable and sends its gradient
through only the one or two examples at the batch midpoint. Mean KL remains in
the objective to provide dense gradients and constrain tail behavior. Model
selection used the matching full-validation `mean KL + P50 KL` value. This run
used the same model, seed, examples, normalization, and 32-epoch cap. It ran all
32 epochs and selected epoch 29.

| Split | Metric | Zero path | Mean-only GLU | Mean + P50 GLU |
| --- | --- | ---: | ---: | ---: |
| Validation | Mean KL | 5.70142 | **4.06536** | 4.19841 |
| Validation | P50 KL | 1.53927 | 1.13613 | **1.05948** |
| Validation | P90 KL | 15.63879 | **15.46745** | 15.47174 |
| Validation | P95 KL | 16.08983 | 16.08146 | **16.07998** |
| Test | Mean KL | 4.78756 | **3.69281** | 3.78670 |
| Test | P50 KL | **0.91404** | 1.14641 | **1.01563** |
| Test | P90 KL | 15.12294 | 14.63730 | **14.61848** |
| Test | P95 KL | **15.75790** | **15.78197** | 15.78827 |

Bold among the two learned models indicates the better GLU; the zero-path cell
is bold only where it beats both learned models.

Relative to mean-only training, the explicit P50 objective lowered validation
P50 by 6.75% and sealed-test P50 by 11.41%. The cost was a 3.27% increase in
validation mean KL and a 2.54% increase in test mean KL. It still reduced mean
test KL by 20.91% versus the zero-path baseline, but its test median remained
11.11% worse than that baseline.

The P50 term therefore works as an optimizer target and generalizes in the
intended direction versus the learned mean-only control. It does not solve the
flat-path baseline's strong median performance, and it slightly sacrifices
average distribution quality.

The improvement is not yet an executable-action improvement. On test,
zero-path modal agreement is 64.86%, slightly above the GLU's 64.30%; total
variation and expected-exposure MAE are also worse. The KL gain comes from how
probability mass is allocated across the full distribution, not from choosing
the correct modal action more often.

The deliberately poor path MSE demonstrates the intended non-identifiability:
many inaccurate price paths can induce similar oracle distributions. That is
acceptable if the only downstream object is the oracle distribution, but the
predicted path must not be interpreted as a calibrated market forecast.

## Conclusion

End-to-end differentiable-oracle training works and generalizes a material KL
improvement over the zero-path oracle. Pure forward KL alone, however, does not
improve the sealed modal action or expected exposure. A next objective should
retain distribution KL while adding an action-relevant term, such as
current-exposure-conditioned KL or expected-regret/value loss, rather than
adding candle MSE merely to make the latent path look realistic.
